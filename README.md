# GFG × MARVEL — Multiverse of Code

A cinematic Marvel-inspired event landing page for the GeeksForGeeks Student Chapter, Bennett University.

## Run
Open `index.html` in a browser.

## Included
- Responsive single-page layout
- Cinematic hero section
- Comic-inspired red/black/gold visual system
- Scroll reveal animations
- Interactive registration CTA
- Event highlights and schedule
- No external image assets required

## Customize
Replace the placeholder event timings/copy in `index.html` with the official event details before submission.
